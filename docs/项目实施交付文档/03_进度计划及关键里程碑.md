## 4. 阶段验收标准

### 4.1 P0 阶段验收标准

- MQTT 基础链路稳定。
- 设备上线、心跳、绑定状态和拓扑上报可用。
- OSD/state、properties、CMD、DRC、Wayline 基础链路可用。
- 错误码、日志和 request trace 可用于问题定位。
- P0 专项脚本能够重复执行。

### 4.2 P1 阶段验收标准

- 一键启航主流程具备可联调能力。
- 机巢状态机、告警、HMS、日志具备闭环。
- 媒体、直播、配置、固件升级模拟具备基础可用能力。
- E2E 测试能够覆盖核心业务链路。

### 4.3 预验收标准

- P0 功能达到可用状态。
- P1 主链路基本闭环。
- 遗留问题有明确责任、影响范围和整改计划。
- 验收脚本、日志、trace 和文档材料齐备。

### 4.4 正式验收标准

- 预验收问题完成整改或形成客户认可的后续计划。
- 核心链路可重复启动、联调和验证。
- 所有交付文档、脚本、配置和验收记录完成归档。
- 项目范围内功能达到正式验收要求。
