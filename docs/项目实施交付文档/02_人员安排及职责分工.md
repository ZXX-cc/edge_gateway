# 人员安排及职责分工

## 1. 团队配置

项目团队共 6 人，包括 1 名项目经理和 5 名研发人员。团队采用项目经理统筹、研发人员按技术域负责的组织方式，确保需求、开发、联调、测试和交付材料能够同步推进。

| 角色 | 人数 | 主要职责 |
|---|---:|---|
| 项目经理 | 1 | 项目计划、进度跟踪、风险协调、客户沟通、验收组织 |
| 研发人员 | 5 | 网关开发、协议适配、飞控/机巢联调、测试验证、文档输出 |

## 2. 项目经理职责

项目经理负责项目整体推进和交付管理，主要职责如下：

1. 制定项目实施计划、阶段目标和里程碑安排。
2. 组织需求澄清，确认项目范围、边界和交付标准。
3. 跟踪每日研发进度，协调跨岗位问题。
4. 组织周会、专项评审、预验收和正式验收。
5. 维护项目风险清单、问题清单和变更记录。
6. 对接客户和相关协作方，推动问题闭环。
7. 汇总交付材料，确认验收资料完整性。

## 3. 研发岗位分工

### 3.1 研发一：上云 API 与 MQTT 协议开发

负责网关与平台之间的协议通信能力，主要职责包括：

- MQTT topic、method、payload、reply 适配。
- services、property/set、requests、status、events、osd、state、drc 通道处理。
- 设备上线、心跳、绑定状态、设备拓扑上报。
- DJI Dock3 上云 API 字段、错误码和回包格式对齐。
- MQTT 专项测试脚本和 request trace 验证。

### 3.2 研发二：飞控通信与 MAVLink 适配

负责网关与飞控平台、SITL、MAVLink 相关能力，主要职责包括：

- MAVLink 连接、遥测接收和飞控状态解析。
- 飞行模式、解锁、起飞、返航、降落等基础控制适配。
- 航点任务、Wayline 与 MAVLink Mission 的联调。
- 飞控异常、超时和状态恢复处理。
- 配合完成真实 SITL 飞行行为验证。

### 3.3 研发三：机巢通信与设备侧 Adapter

负责机巢模拟器和机巢协议相关能力，主要职责包括：

- 机巢 v1.3 协议解析和命令适配。
- 舱盖、推杆、充电、补光灯、急停、故障等状态同步。
- 机巢状态到 Dock3 state、HMS、dock_operation 的映射。
- 机巢模拟器联调、状态机验证和异常恢复。
- 一键启航中机巢动作链路配合。

### 3.4 研发四：任务、媒体、日志和运维能力开发

负责任务流程和运维类能力，主要职责包括：

- Wayline 航线任务基础闭环和任务进度上报。
- DRC 指点飞行、一键起飞相关任务状态配合。
- 媒体文件、直播 mock、上传进度和日志上传能力。
- HMS 告警、远程日志、配置更新、固件升级模拟。
- 任务状态、操作记录和运维事件验证。

### 3.5 研发五：测试、部署和集成验证

负责项目测试体系、部署脚本和联调环境，主要职责包括：

- MQTT Broker、云端模拟器、机巢模拟器和网关启动脚本维护。
- 专项测试脚本、E2E 测试脚本和测试数据准备。
- Ubuntu 模拟环境部署、问题复现和日志采集。
- 联调问题定位、回归测试和验收证据归档。
- 配合项目经理准备预验收和正式验收材料。

## 4. 协作机制

1. 每日同步进度、风险和阻塞问题。
2. 每周组织阶段评审，确认功能完成度和剩余缺口。
3. 协议字段、接口行为和错误码调整必须同步到文档。
4. 关键功能完成后必须提供脚本、日志或 trace 作为证据。
5. 涉及跨模块的问题由项目经理协调责任人共同处理。

## 5. 职责边界

本项目研发职责集中在网关侧。平台侧前端页面、权限、工单、长期统计、媒体资源库和业务运营能力不由本项目研发团队交付；如联调需要相关平台能力，由项目经理统一协调客户或平台团队配合。
