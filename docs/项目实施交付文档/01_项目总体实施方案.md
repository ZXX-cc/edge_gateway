# 项目总体实施方案

## 1. 项目概述

本项目建设目标是完成边缘网关相关能力的设计、开发、联调和验收，重点围绕设备接入、上云通信、协议适配、状态上报、任务控制、日志追踪和模拟环境验证展开。项目交付范围以网关侧能力为主，平台侧业务系统、前端页面、用户权限、长期统计和业务工单等内容不纳入本项目开发范围。

项目计划周期为 45 个自然日，项目开始日期为 2026 年 7 月 7 日。第 35 个自然日进行预验收，第 45 个自然日进行正式验收。

## 2. 建设目标

1. 完成网关侧核心通信链路建设，确保 MQTT、设备状态、遥测、事件、指令回复和请求响应链路可用。
2. 完成网关与飞控、机巢模拟器、云端模拟器之间的基础联调。
3. 建立设备上线、心跳、拓扑上报、OSD/state 上报、命令控制、DRC、航线任务、告警和日志等核心能力。
4. 形成可重复执行的验收脚本、联调记录、日志和问题闭环。
5. 完成 35 天预验收和 45 天正式验收所需的交付材料。

## 3. 实施范围

### 3.1 网关侧开发范围

- MQTT topic、method、payload、reply 协议适配。
- 设备上线、心跳、绑定状态、设备拓扑上报。
- OSD 定频遥测和 state 状态变更上报。
- services、property/set、requests、status、drc 等消息通道处理。
- 机巢模拟器、飞控平台和网关之间的联调适配。
- DRC、CMD、Wayline、HMS、日志、配置、固件升级模拟等网关侧能力。
- 日志、request trace、错误码、异常处理和验收脚本。

### 3.2 不纳入本项目范围

- 平台前端页面开发。
- 用户、角色、权限体系。
- 业务工单、业务审批流。
- 长期历史统计、报表和数据仓库。
- 媒体资源库平台侧管理。
- 多设备批量业务调度平台能力。
- 真实硬件生产环境部署和生产级 TLS/鉴权。

## 4. 技术实施路线

项目采用分阶段实施方式，先完成基础通信链路，再补齐设备状态、控制指令、任务流程和验收闭环。

### 4.1 基础链路建设

完成 MQTT Broker、云端模拟器、网关、飞控平台、机巢模拟器之间的启动和通信验证，确保网关能够正常接收平台消息，并按协议返回响应。

### 4.2 设备接入与状态同步

完成设备上线、心跳、绑定状态查询、设备拓扑 `update_topo`、OSD/state 上报、设备属性读写等功能。

### 4.3 控制与任务能力建设

完成基础 CMD 控制、DRC 建链和控制、Wayline 航线任务基础闭环、飞控基础控制和机巢基础状态同步。

### 4.4 告警、日志和运维能力建设

完成 HMS 告警、远程日志、配置更新、固件升级模拟、错误码映射、request trace 和运行日志留存。

### 4.5 联调与验收

通过专项脚本和 E2E 脚本完成联调验证，形成验收记录、问题清单、修复记录和最终交付说明。

## 5. 交付成果

- 网关侧核心功能代码。
- 配置文件、启动脚本和联调脚本。
- P0/P1/P2 功能覆盖说明。
- 接口联调记录和验收脚本输出。
- 问题清单、风险清单和处理记录。
- 预验收材料和正式验收材料。

## 6. 验收原则

1. 网关侧核心链路必须可重复启动和验证。
2. 平台发送的核心指令必须有明确回复。
3. 网关主动上报的状态、事件、拓扑和遥测必须符合约定 topic 和 payload。
4. P0/P1 主链路功能必须达到可用状态。
5. 未接真实硬件的能力必须给出 mock、adapter、限制说明和后续计划。
