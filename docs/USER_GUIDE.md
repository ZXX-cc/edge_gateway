# Edge Gateway 操作手册

本文档说明 Windows 环境下 Edge Gateway 操作页面的启动、日常操作和停止方法。默认访问地址为 `http://127.0.0.1:8095`。

## 1. 每日启动

如果 MongoDB 和 Mosquitto 已配置为自动启动，只需确认服务状态：

```powershell
Get-Service MongoDB, mosquitto
```

两项状态应为 `Running`。

按照 [Windows 部署文档](DEPLOYMENT_GUIDE.md) 的顺序启动：

1. 机巢模拟器或真实机巢。
2. 云端模拟器或真实云端平台。
3. Edge Gateway。
4. Demo Platform 操作页面。

浏览器打开：

```text
http://127.0.0.1:8095
```

## 2. 页面说明

页面左侧包含：

| 页面 | 作用 |
|---|---|
| 飞行总览 | 查看网关、机场、飞行器和遥测状态 |
| APIDock3 命令 | 查询属性，控制舱盖、推杆、充电和补光灯 |
| 真实航线 | 准备、执行、暂停、恢复、返航和终止航线 |
| DRC 飞控 | 进入 DRC、发送心跳和速度指令、退出 DRC |
| 飞行日志 | 查看遥测、事件和命令结果 |
| 复测留证 | 运行验收项目并保存结果 |
| 原始报文 | 查看最近的 MQTT 报文，排查通信问题 |

右上角“APIDock3 单条命令”用于调试，不熟悉 MQTT method 和 JSON 参数时不要使用。

## 3. 飞行总览

进入系统后首先查看“飞行总览”。

### 3.1 MQTT 状态

页面左下角应显示：

```text
MQTT 已连接
```

如果显示“未连接”，不要执行任何控制操作，先检查 Mosquitto、网关和页面启动窗口。

### 3.2 机场状态

机场卡片显示：

- 网关编号。
- 舱盖状态。
- 推杆状态。
- 充电状态。
- 风速。

### 3.3 飞行器状态

飞行器卡片显示：

- 飞行器编号。
- 电量。
- 高度。
- 飞行模式。
- GPS/RTK 状态。

未连接飞控时显示“等待 OSD”属于正常情况。

### 3.4 刷新

点击右上角“刷新”更新页面快照。不要连续快速点击。

## 4. 查询核心状态

1. 点击左侧“APIDock3 命令”。
2. 点击“核心属性查询”。
3. 等待“最近结果”显示成功。
4. 返回“飞行总览”核对舱盖、推杆、充电、飞行模式和 DRC 状态。

如果结果显示失败或超时，不要连续重试，先检查网关和设备连接。

## 5. 机场机构操作

### 5.1 进入远程调试

1. 打开“APIDock3 命令”。
2. 点击“进入远程调试”。
3. 等待结果成功后再执行机构动作。

### 5.2 舱盖

- 点击“打开舱盖”执行开盖。
- 点击“关闭舱盖”执行关盖。

命令返回后，回到飞行总览确认舱盖状态已经变化。

### 5.3 充电和推杆

起飞准备的常用顺序：

1. 打开舱盖。
2. 点击“关闭充电”，断开充电。
3. 点击“打开推杆”，释放飞行器固定机构。

回收飞行器时，根据现场流程点击“关闭推杆”，确认飞行器已经夹紧。

### 5.4 补光灯

- 点击“打开补光灯”开启补光灯。
- 点击“关闭补光灯”关闭补光灯。

### 5.5 退出远程调试

所有机构操作完成后点击“退出远程调试”。

不要在机构运动过程中连续点击相反命令。真实机巢首次操作时必须有人现场观察。

## 6. 航线操作

打开左侧“真实航线”。

### 6.1 执行前检查

确认：

- 飞行器在线且电量充足。
- GPS/RTK 和飞控模式正常。
- 舱盖已打开、充电已断开、推杆已释放。
- 当前没有 DRC 控制和其他航线任务。
- 测试航线和现场环境安全。

### 6.2 准备和执行

1. 点击“解锁 QLAN 模式”。
2. 点击“准备 SITL HD 航线”。
3. 等待航线准备成功。
4. 点击“执行航线”。
5. 点击“查询任务进度”查看当前进度。
6. 在“飞行总览”和“飞行日志”中观察高度、经纬度、模式和进度。

页面中的 HD 航线是测试航线。没有连接 SITL 或真实飞控时，不要执行航线。

### 6.3 暂停和恢复

- 点击“暂停航线”暂停当前任务。
- 确认飞行器状态稳定后，点击“恢复航线”。

### 6.4 返航和终止

- 点击“任务返航”请求飞行器返航。
- 点击“终止任务”取消当前任务。
- 点击“取消返航”取消正在执行的返航。

命令返回成功不代表飞行器已经落地，必须继续观察飞行器状态。

## 7. DRC 操作

DRC 会占用飞行器控制权，不能与航线任务同时操作。

### 7.1 进入 DRC

1. 打开左侧“DRC 飞控”。
2. 点击“进入 DRC”。
3. 等待结果成功。
4. 返回飞行总览确认 DRC 状态已更新。

### 7.2 心跳和速度测试

1. 点击“发送心跳”。
2. 点击“速度推送”发送一帧低速测试数据。
3. 观察飞行器状态和日志。

只有在 SITL 或经过现场确认的真实飞控环境中才能执行速度测试。

### 7.3 退出 DRC

操作完成后点击“退出 DRC”，并确认 DRC 状态恢复为空闲。

页面超时、遥测停止更新或飞行器响应异常时，立即停止继续发送指令。

## 8. 飞行日志

打开左侧“飞行日志”。

页面包含：

- 遥测时间线：电量、高度、经纬度和飞行模式。
- 事件时间线：任务进度、设备事件和命令结果。
- HMS 查询：查看当前告警。
- 日志列表：查看可用日志。

出现问题时记录：

1. 发生时间。
2. 网关和飞行器编号。
3. 执行的操作。
4. 页面结果和错误信息。

不要删除当日日志。

## 9. 复测留证

“复测留证”用于项目验收。

1. 打开“复测留证”。
2. 选择需要执行的项目。
3. 点击“运行测试”。
4. 根据结果选择“通过”“失败”或“需真实数据”。
5. 在备注中记录现象、时间和错误原因。

复测项目可能控制飞控或机巢。执行前确认当前测试环境允许对应操作。

## 10. 原始报文

“原始报文”显示最近的 MQTT 数据，可按以下类型筛选：

- 全部。
- OSD。
- 回包。
- 事件。
- 状态。

该页面用于排查通信问题，日常操作不需要修改或发送原始报文。

## 11. 常见状态

| 页面结果 | 含义 | 处理方法 |
|---|---|---|
| 成功 | 网关已返回成功结果 | 继续确认设备状态和现场动作 |
| 失败 | 网关或设备拒绝执行 | 查看错误信息，检查前置状态 |
| 超时 | 规定时间内没有收到结果 | 检查 MQTT、网关和设备连接 |
| 等待数据 | 尚未收到对应遥测或状态 | 等待数据或检查设备连接 |
| 需真实数据 | 当前环境缺少真实飞控/机巢数据 | 连接对应设备后重新测试 |

## 12. 紧急处理

出现以下情况时停止继续点击：

- 飞行器状态异常。
- 页面长时间不更新。
- 机巢机构卡住。
- DRC 控制权状态不明确。
- 同一命令出现多个互相冲突的结果。

优先使用现场人工接管或物理急停。确保设备安全后，保留页面结果和日志。

## 13. 停止系统

停止前确认没有正在执行的航线、DRC、机构动作或日志上传。

在各启动窗口中按 `Ctrl+C`，按以下顺序停止：

1. Demo Platform。
2. Edge Gateway。
3. 云端模拟器。
4. 机巢模拟器。

不要直接关闭正在执行任务的窗口，也不要在飞行器未落地时关闭系统。

## 14. 常见问题

| 问题 | 处理方法 |
|---|---|
| 页面打不开 | 确认 Demo Platform 窗口正在运行，检查 `8095` 端口 |
| MQTT 未连接 | 检查 Mosquitto 和 Edge Gateway 窗口 |
| 机场状态不更新 | 检查机巢或机巢模拟器窗口 |
| 飞行器等待 OSD | 检查飞控/SITL 是否向 `14550` 发送数据 |
| 命令超时 | 不要连续重试，先检查各组件连接 |
| 一个命令出现多个回包 | 关闭重复运行的网关或模拟器 |
| DRC 无法进入 | 退出当前任务，检查飞行器在线和告警状态 |
| 航线无法执行 | 检查飞控、航线准备、设备状态和 DRC 占用 |

安装和配置见 [Edge Gateway Windows 部署文档](DEPLOYMENT_GUIDE.md)。
