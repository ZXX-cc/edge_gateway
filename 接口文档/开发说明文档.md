## 一、项目概述

**Edge Gateway** 是一个基于树莓派的 DJI Cloud API 边缘网关，适配大疆（DJI）上云 API 协议 v1.15。它作为设备端网关，通过 MQTT 与云端通信，通过 MAVLink 与飞控（ArduPilot/PX4）及机巢通信，实现完整的设备端接口。

## 三、接口开发规范

### 3.1 接口类型分类

DJI Cloud API 中接口分为三大类，开发方式不同：

| 类型 | 方向 | 注册方式 | 示例 |
|------|------|---------|------|
| **services** | 云→设备 | `TopicRouter.register(method, handler)` | `camera_photo_take`, `dock_control` |
| **requests/requests_reply** | 设备↔云双向 | 同上 + `CloudConnectionManager.send_request()` | `config`, `update_topo` |
| **events** | 设备→云 | **无需注册**，业务主动调用 `report_xxx()` | `ota_progress`, `hms`, `drc_status_notify` |
| **osd/state** | 设备→云 | **无需注册**，由 TelemetryProcessor 定时/变更触发 | `osd` 定频上报, `state` 变更上报 |

### 3.2 Handler 开发规范

所有 services 类型的接口 handler 遵循**统一签名**：

```python
def handle_<method_name>(self, msg: dict) -> dict:
    """
    接口逻辑说明
    
    Args:
        msg: {
            "tid": "事务UUID",
            "bid": "业务UUID",
            "timestamp": 1667220873846,
            "gateway": "网关SN",
            "method": "方法名",
            "data": { ... },          # 业务请求数据
            "need_reply": 1           # 可选，是否需要响应
        }
    
    Returns:
        响应消息 dict，使用 MessageBuilder.build_reply() 构造
    """
    data = msg.get('data', {})
    
    # 1. 参数校验
    # 2. 业务逻辑执行
    # 3. 状态更新（物模型属性等）
    # 4. 构造响应
    
    return MessageBuilder.build_reply(msg, result=0, data={...})
```

### 3.3 响应消息构造

```python
from src.utils.message import MessageBuilder

# 成功响应
return MessageBuilder.build_reply(msg, result=0, data={"key": "value"})

# 失败响应
return MessageBuilder.build_reply(msg, result=-1, data={}, msg_str="错误描述")

# 复杂响应（含嵌套结构）
return MessageBuilder.build_reply(msg, result=0, data={
    "status": "running",
    "progress": {
        "current_step": 3,
        "percent": 60
    }
})
```

**result 码规范**：

| result | 含义 |
|--------|------|
| 0 | 成功 |
| -1 | 通用失败/内部错误 |
| -2 | 未知方法 |
| 其他 | 按业务定义（如参数错误=-3，设备离线=-4 等） |

### 3.4 事件上报开发规范

events 类型接口**不需要在 TopicRouter 注册**，由业务逻辑在适当时机主动调用：

```python
from src.utils.message import MessageBuilder

# 在业务模块中定义事件上报方法
def report_xxx_event(self, **kwargs):
    """上报 xxx 事件"""
    if self._event_callback:
        event = MessageBuilder.build_event(
            method='事件方法名',
            data={
                'key1': value1,
                'key2': value2,
                # ... 对齐 DJI 文档的事件数据结构
            },
            gateway_sn=self.gateway_sn
        )
        self._event_callback(event)
```

**事件回调注入方式**（在 `main.py` 的 `_setup_callbacks()` 中）：

```python
def event_cb(event):
    self.mqtt.publish_event(event)

self.module.set_event_callback(event_cb)
```

### 3.5 状态变更上报（state）

当物模型属性发生变更时，通过 state 上报：

```python
# 在 DeviceManager 或 DockManager 中
self._state_callback({'property': {name: value}})
```

state 上报的触发时机：
- 物模型属性值变更
- 设备状态机切换
- 拓扑结构变更（通过 `sys/product/{sn}/status` 通道）

### 3.6 注册 Handler 到 Router

在 `src/main.py` 的 `EdgeGateway._register_handlers()` 中统一注册：

```python
self.router.register_batch({
    'method_name_1': self.module.handle_method_name_1,
    'method_name_2': self.module.handle_method_name_2,
    # ...
}, category='device')  # category: device/mission/payload/media/drc/dock/log/flysafe/flight_area/custom_data
```

**注意**：
- 新增的 handler 必须在此注册，否则无法被路由
- `category` 仅用于分类管理，不影响路由逻辑
- 如果方法名与现有 handler 冲突，后注册的会覆盖先注册的

## 四、MAVLink 通信开发规范

### 4.1 获取 MAVLink 连接

业务模块中通过 setter 注入获取 MAVLink 连接：

```python
# 在模块中定义注入方法
def set_mavlink_connection(self, conn):
    self._mavlink_conn = conn

# 在 main.py 中注入
self.camera.set_mavlink_connection(self.mavlink_conn)
```

发送 MAVLink 命令：

```python
conn = self._mavlink_connection
master = conn.master

# 发送命令
master.mav.command_long_send(
    master.target_system,
    master.target_component,
    mavutil.mavlink.MAV_CMD_DO_SET_MODE,
    0,  # confirmation
    param1, param2, param3, param4, param5, param6, param7
)
```

### 4.2 自定义 Dialect（机巢协议）

机巢使用自定义 MAVLink dialect，通过 `generated_dialect/drone_nest.py` 定义：

```python
from src.generated_dialect.drone_nest import MAVLink_drone_nest_message

# 发送机巢命令
conn.master.mav.drone_nest_command_send(
    ordinary_order=cmd_value,
    takeoff_land_order=takeoff_value
)
```

### 4.3 消息接收（新架构）

新架构下通过 `MessageDispatcher` 的钩子机制接收 MAVLink 消息：

```python
            pass
```

以 **完善 `camera_photo_take` 的拍照进度上报** 为例：

#### 步骤 1：确认接口定义

查阅 `接口文档/dji_doc/cmd.md` 或 `DJI_Dock_MQTT_API_完整接口文档_v1.15.md`，确认：

#### 步骤 2：修改业务模块

```python
# src/payload/camera.py

class CameraController:
    def __init__(self):
        # ... 现有代码 ...
        self._event_callback = None
    
    def set_event_callback(self, callback):
        self._event_callback = callback
    
    def handle_camera_photo_take(self, msg: dict) -> dict:
        """
        相机拍照
        
        已实现：发送 MAVLink 拍照命令
        TODO：实现拍照进度事件上报
        """
        data = msg.get('data', {})
        
        # 发送 MAVLink 拍照命令
        conn = self._get_mavlink_connection()
        if conn:
            conn.master.mav.command_long_send(
                conn.master.target_system,
                conn.master.target_component,
                mavutil.mavlink.MAV_CMD_DO_DIGICAM_CONTROL,
                0, 0, 0, 0, 0, 1, 0, 0  # param5=1 触发拍照
            )
        
        self._photo_count += 1
        
        # TODO: 拍照完成后上报进度事件
        # self._report_photo_progress()
        
        return MessageBuilder.build_reply(msg, result=0, data={
            'photo_index': self._photo_count
        })
    
    def _report_photo_progress(self, status: str, percent: int = 0):
        """上报拍照进度事件（开发任务）"""
        if self._event_callback:
            event = MessageBuilder.build_event(
                method='camera_photo_take_progress',
                data={
                    'output': {
                        'status': status,  # 'in_progress' / 'completed' / 'failed'
                        'progress': {
                            'percent': percent,
                            'step_key': 'camera_photo_take'
                        }
                    }
                },
                gateway_sn=self.gateway_sn
            )
            self._event_callback(event)
```

```python
# src/payload/camera.py

def handle_camera_histogram_get(self, msg: dict) -> dict:
    """
    获取相机直方图（示例新增接口）
    
    Request: { }
    Response: { result, histogram: { r: [], g: [], b: [], luma: [] } }
    """
    # 1. 从 MAVLink 或相机 SDK 获取直方图数据
    histogram = self._fetch_histogram_from_camera()
    
    if histogram is None:

            msg, result=-1, msg_str="Failed to get histogram"

    # 2. 返回数据
    return MessageBuilder.build_reply(msg, result=0, data={
        'histogram': histogram
    })
```

```python
# src/main.py _register_handlers()

self.router.register_batch({
```
